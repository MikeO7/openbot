### Added

- You can set one agent as your main agent: press and hold the agent in the chat list, then tap
  "Set as main agent". A round button at the right of the home search field shows the main agent.
  Tap it to open the chat of that agent with the message field ready. Press and hold it to start a
  new thread with the agent or to choose another main agent. With no main agent, a tap on the button
  lists your agents. The choice stays on this phone.
